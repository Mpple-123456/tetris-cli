# 🧩 Terminal Tetris

经典俄罗斯方块游戏，运行在终端中。

## 🚀 快速开始

### git clone https://github.com/Mpple-123456/tetris-cli.git
### cd tetris-cli
# Windows 用户需安装 windows-curses
### pip install windows-curses
### python main.py

# 操作说明

| 按键 | 功能 |
| :--- | :--- |
| `←` / `→` | 左右移动方块 |
| `↑` | 旋转方块 |
| `↓` | 加速下落（软降） |
| `空格` | 直接落底（硬降） |
| `Q` | 退出游戏 |
